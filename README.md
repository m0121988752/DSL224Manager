# تطبيق إدارة راوتر D-Link DSL-224 الشامل (iOS v2.0)

تطبيق iOS متكامل، خفيف وسريع، مصمم لإدارة راوتر **D-Link DSL-224 (Rev R1 - ME_1.10)** أو عدة راوترات في نفس الوقت، مع **ودجت الشاشة الرئيسية وشاشة القفل** وحماية باقة الإنترنت من الاستنزاف.

## 🌟 المميزات الشاملة (الإصدار 2.0)
- **إدارة راوترات متعددة:** أضف أكثر من راوتر (راوتر المنزل، راوتر المكتب، راوتر الاستراحة...) وبدّل بينها بضغطة واحدة مع باقة مستقلة وأجهزة مستقلة لكل راوتر.
- **ودجت الشاشة الرئيسية وشاشة القفل (`WidgetKit`):**
  - ودجت صغير ومتوسط للشاشة الرئيسية يعرض المتبقي من الباقة، النسبة المئوية، المعدل اليومي الآمن، وعدد الأجهزة المتصلة.
  - ودجت دائري ومستطيل لشاشة القفل في الآيفون لمتابعة الباقة بلمحة سريعة.
- **العمل في الخلفية والأتمتة الذكية (`BGAppRefreshTask` + `dsl224://sync`):**
  - جدولة تلقائية في الخلفية لتحديث العداد والودجت.
  - دعم رابط الاستدعاء السريع `dsl224://sync` لربطه بتطبيق Shortcuts ليحدث الباقة تلقائياً فور الاتصال بواي فاي المنزل.
- **تحكم كامل بالأجهزة المتصلة:**
  - فصل وحظر أي جهاز بضغطة واحدة (MAC Filter).
  - تحديد السرعة (256K، 512K، 1M، 2M، أو **سرعة مخصصة بالكيلوبت**، أو سرعة كاملة).
  - تسمية الأجهزة وحفظها دائماً + تمييز الأجهزة الموثوقة + البحث والفلترة + إضافة جهاز يدوياً.
- **حساب استهلاك الباقة ومقاومة إعادة التشغيل:**
  - يحسب الفروقات التراكمية للبايتات ولا يتأثر بانقطاع الكهرباء أو ريستارت الراوتر.
  - يحسب المعدل اليومي الآمن لإكمال الشهر دون نفاد الباقة.
  - معايرة سريعة للاستهلاك إذا بدأت استخدام التطبيق في منتصف الشهر.
- **شاشة إعدادات شاملة + نسخ احتياطي:**
  - التحكم في نسب التنبيه المئوية (إضافة أو حذف أي نسبة مثل 50%، 75%، 90%، 95%).
  - تصدير واستيراد كل الإعدادات والراوترات وأسماء الأجهزة بصيغة JSON.
