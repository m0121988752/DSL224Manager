# تطبيق إدارة راوتر D-Link DSL-224 (iOS)

تطبيق iOS خفيف وسريع مصمم خصيصاً لإدارة راوتر **D-Link DSL-224 (Rev R1 - ME_1.10)** وحماية باقة الإنترنت من الاستنزاف.

## 🌟 المميزات
- **قطع الإنترنت (Kick / Block):** حظر أي جهاز متصل بالشبكة بضغطة واحدة عبر MAC Filter.
- **تحديد السرعة (Bandwidth Limiting):** خيارات لتقييد السرعة (512 كيلوبت، 1 ميجابايت، أو سرعة كاملة) عبر Traffic Control.
- **حساب استهلاك الباقة التراكمي:** حفظ دائم للبيانات داخل الهاتف ومقاومة تصفير العداد عند انقطاع الكهرباء أو إعادة تشغيل الراوتر.
- **إشعارات ذكية:**
  - تنبيه فوري عند دخول أي جهاز غريب للشبكة.
  - تنبيهات عند تخطي نسب محددة من الباقة (50%، 75%، 90%).
- **تسمية مخصصة للأجهزة:** إمكانية تعديل اسم أي جهاز بالاسم الذي تفضله بدلاً من الماك أدرس غير المفهوم.
- **واجهة عربية داكنة خفيفة:** بدون تكلف أو بطء، مع دعم كامل لاتجاه اليمين (RTL).

## 🚀 التثبيت عبر Sideloadly
1. من تبويب **Actions** في هذا المستودع، اضغط على أحدث عملية بناء خضراء.
2. انزل لأسفل الصفحة وحمّل ملف **`DSL224Manager-IPA`**.
3. قم بفك الضغط عن الملف لتحصل على `DSL224Manager.ipa`.
4. افتح برنامج **Sideloadly** على حاسوبك، وصِل الآيفون بالـ USB.
5. اسحب ملف `.ipa` إلى Sideloadly، واكتب حساب Apple ID واضغط **Start**.
6. بعد التثبيت على الهاتف، اذهب إلى:
   **الإعدادات ➔ عام ➔ إدارة الجهاز (VPN & Device Management)**، واضغط على حسابك ثم **الوثوق (Trust)**.
