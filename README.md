# تطبيق إدارة الراوترات الشامل (DSL224Manager)

تطبيق متكامل وخفيف لإدارة راوترات الشبكة المنزلية وراوترات الجيل الرابع (4G/LTE)، مصمم لتتبع استهلاك الباقة بدقة وحمايتها من الاستنزاف والتحكم في الأجهزة المتصلة.

يدعم التطبيق حالياً:
1. **راوترات D-Link**: موديل **DSL-224** (بما في ذلك إصدارات Boa ME_1.10 و Realtek Generic).
2. **راوترات Huawei 4G / LTE**: عائلة **B311-221** و **Airbox / Flybox** المعتمدة على بروتوكول المصادقة المتقدم **SCRAM-SHA256**.

---

## 🌟 المميزات الرئيسية

### 1. دعم راوترات متعددة (Multi-Router Profiles)
- إضافة وإدارة أكثر من راوتر في نفس التطبيق (راوتر المنزل، راوتر 4G الهوائي، راوتر العمل، إلخ).
- التبديل الفوري بين الراوترات مع باقة مستقلة وإعدادات مستقلة لكل جهاز.

### 2. تكامل متقدم مع راوترات Huawei B311-221
- **مصادقة SCRAM-SHA256 كاملة**: دعم المصافحة الأمنية المخصصة لراوترات هواوي الحديثة (`challenge_login` و `authentication_login`).
- **حظر وفصل الأجهزة المباشر**: إضافة وإزالة الأجهزة من القائمة السوداء باستخدام واجهة `api/wlan/multi-macfilter-settings`.
- **قراءة إحصائيات الشريحة المباشرة**:
  - اسم الشبكة والمزود (Carrier Name / PLMN).
  - سرعات التحميل والرفع الحية اللحظية (Live Kbps).
  - الاستهلاك الشهري التراكمي المدمج في الراوتر مباشرة بدون الحاجة لحسابات خارجية.

### 3. تحكم كامل بالأجهزة المتصلة
- **فصل وحظر الأجهزة بضغطة واحدة** عبر MAC Filter للراوتر النشط.
- **تحديد السرعة (Bandwidth Control)**: تحديد سرعات الأجهزة لراوترات D-Link (256K, 512K, 1M, أو سرعة مخصصة).
- **إدارة الهوية**: تسمية مخصصة للأجهزة وتعيين الأجهزة الموثوقة (Trusted) لتسهيل تمييزها.
- **إضافة أجهزة يدوياً**: إضافة أجهزة بواسطة عنوان MAC مباشرة.

### 4. عداد الباقة الذكي ومقاومة إعادة التشغيل
- حساب استهلاك الباقة التراكمي ومقاومة تصفير الراوتر عند انقطاع الكهرباء أو إعادة التشغيل.
- حساب المعدل اليومي الموصى به لإكمال الشهر بأمان.
- سجل تاريخي لاستهلاك الباقة يوماً بيوم لآخر 30 يوماً.
- تنبيهات مخصصة عند تجاوز نسب معينة من الباقة (مثلاً 50%، 80%، 90%).

### 5. ودجت وأتمتة الخلفية (iOS)
- **ودجت الشاشة الرئيسية وشاشة القفل (`WidgetKit`)**: متابعة رصيد الباقة وسرعة النت بلمحة سريعة.
- **العمل في الخلفية (`BGAppRefreshTask`)**: تحديث دوري ذكي لبيانات الراوتر.
- **روابط الاختصارات (`dsl224://`)**:
  - `dsl224://sync`: للتحديث التلقائي عبر تطبيق Shortcuts عند الاتصال بالواي فاي.
  - `dsl224://reboot`: لإعادة تشغيل الراوتر عن بُعد.

### 6. المتصفح البديل وكشط واجهة الويب والضغط على الأزرار (WebUI Fallback & Automation)
- **بديل ذكي تلقائي (Fallback)**: في حال تعذر الاتصال المباشر عبر API أو اختلاف البرامج الثابتة، يقوم التطبيق بتشغيل محرك WebKit (`WKWebView`) في الخلفية لجلب البيانات.
- **تسجيل الدخول التلقائي (Auto-Login)**: حقن بيانات الدخول تلقائياً والنقر على زر الدخول أو إرسال النموذج.
- **كشط محتوى DOM (DOM Scraping)**:
  - استخراج عدادات بايتات الـ WAN التراكمية وسرعات الرفع والتحميل.
  - استخراج جداول الأجهزة المتصلة وعناوين MAC و IP وأسماء الأجهزة.
- **الضغط الآلي على الأزرار (Button Automation)**:
  - البحث بالمعنى الدلالي وضغط أزرار إعادة التشغيل (`Reboot`)، الحفظ (`Save/Apply`)، والتحديث.
  - الضغط عبر محددات CSS المخصصة أو نصوص الأزرار مع تجاوز التنبيهات المنبثقة (`window.confirm`).
- **لوحة متصفح الراوتر التفاعلية المدمجة (`RouterWebUIView`)**:
  - فتح وتصفح واجهة الراوتر مباشرة من داخل التطبيق.
  - شريط أدوات سريع: دخول تلقائي، كشط ومزامنة بضغطة واحدة، ضغط زر Reboot، واستكشاف جميع أزرار الصفحة للضغط على أي منها.

## 🛠️ البناء والتثبيت

المشروع يعتمد على **GitHub Actions** للبناء السحابي التلقائي بدون الحاجة لجهاز Mac محلي:
- كل `git push` لفرع `main` يُنشئ ملف **IPA** موثق ومعد للتثبيت عبر:
  - **TrollStore** (بدون شهادة أو إعادة توقيع).
  - **AltStore / Sideloadly** (باستخدام حساب Apple ID مجاني).
- ملفات الـ IPA متاحة دائماً في صفحة [GitHub Actions](https://github.com/m0121988752/DSL224Manager/actions).
